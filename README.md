# 함미합삐 타자연습 ⌨️

할머니, 할아버지를 위한 **큰 글씨 · 쉬운 구성**의 한글 타자연습 사이트입니다.
한컴타자연습의 골격(자리연습 → 낱말 → 짧은글 → 긴글)을 따르고, 미니게임 2종을 더했습니다.

## 구성

| 메뉴 | 내용 |
|---|---|
| 1단계 자리연습 | 가운뎃줄 → 윗줄 → 아랫줄 → 쌍자음(Shift) → 종합. 화면 자판에 다음 글쇠와 손가락을 표시 |
| 2단계 낱말연습 | 쉬운 낱말 / 긴 낱말 15개. 다 치면 자동으로 다음 낱말 |
| 3단계 짧은글연습 | 속담 / 일상 문장 10개. 띄어쓰기와 문장 부호 포함 |
| 4단계 긴글연습 | 진달래꽃, 서시, 애국가, 손주에게 쓰는 편지 등을 한 줄씩. **내 글 넣기**로 노래 가사·시를 직접 넣어 연습 가능 (브라우저에 저장) |
| 게임 · 낱말비 | 떨어지는 낱말을 바닥에 닿기 전에 치기 (빠르기 3단계) |
| 게임 · 글쇠 두더지 | 두더지가 든 글자의 글쇠를 45초 동안 누르기 |
| 로그인 / 회원가입 | 이름 + 숫자 4자리 비밀번호. 서버 없이 브라우저에 저장되며, 한 번 로그인하면 나가기 전까지 유지 |
| 랭킹 | 같은 컴퓨터에서 연습한 사람들끼리 항목별(타수·게임 점수·연습 횟수) 순위 비교 |

- 타수(타/분)와 정확도를 한컴 방식과 같이 **자모 단위**로 계산합니다.
- 글자 크기 3단계, 효과음, 화면 자판 표시, 낱말 읽어주기(TTS) 설정을 제공합니다.
- 계정, 최고 기록, 내 글, 설정은 모두 브라우저 `localStorage`에만 저장됩니다. 서버가 없으므로 다른 컴퓨터와는 공유되지 않습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```
