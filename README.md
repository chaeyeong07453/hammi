# 함미합삐 타자연습 ⌨️

할머니, 할아버지를 위한 **큰 글씨 · 쉬운 구성**의 한글 타자연습 사이트입니다.
한컴타자연습의 골격(낱말 → 짧은 글 → 긴 글)을 따르고, 미니게임 2종을 더했습니다.

## 구성

| 메뉴 | 내용 |
|---|---|
| 1단계 낱말 연습 | 쉬운 낱말(520개) / 긴 낱말(360여 개) 중 매번 15개를 무작위로. 다 치면 자동으로 다음 낱말 |
| 2단계 짧은 글 연습 | 속담 / 일상 문장 10개. 띄어쓰기와 문장 부호 포함 |
| 3단계 긴 글 연습 | 진달래꽃, 서시, 애국가, 흥부와 놀부 등을 한 줄씩. **내 글 넣기**로 노래 가사·시를 직접 넣어 연습 가능 (브라우저에 저장). **모두에게 공유하기**를 누르면 Supabase에 저장되어 모든 방문자의 "함께 보는 글" 목록에 바로 나타남. 로그인한 채로 올린 글은 내 계정으로, 그 외에는 올릴 때 정한 비밀번호 4자리로 고치기·지우기 가능 |
| 게임 · 낱말비 | 떨어지는 구절·속담·문장을 바닥에 닿기 전에 치기 (빠르기에 따라 짧은 구절 → 긴 문장). 90초 또는 5개 놓치면 종료, 잠깐 멈춤·그만하기 지원 |
| 게임 · 낱말 두더지 | 두더지가 든 낱말을 45초 동안 쳐서 잡기 (빠르기에 따라 낱말 길이 증가) |
| 게임 · 단어 드라이브 (3D) | 내 차는 도로 아래에 이름표와 함께 서 있고, 낱말·구·문장이 둥근 표지로 다가옴. 먼저 친 사람이 득점: 1~2글자 10점, 3~4글자 20점, 구 30점, 문장 50점. 빠르기 3단계(방장이 정함), 1~3명, 초대 코드/상대 찾기, 90초 |
| 게임 · 끝말 테니스 (3D) | 끝말잇기. 컴퓨터(곰돌 코치) 또는 친구와 온라인 대전(최대 6명, 접속 순서대로 돌아가며 침). 난이도 3단계(쉬움 30초·보통 20초·어려움 12초, 쉬움·보통은 친숙한 낱말만·어려움은 사전 낱말), 표준국어대사전 표제어로 검증, 두음법칙 허용, 단어 아래 뜻풀이, 곰에 이름표, 생명 3개 |
| 로그인 / 회원가입 | 이름 + 숫자 4자리 비밀번호. 계정은 Supabase에 저장되어 어느 컴퓨터·휴대폰에서든 같은 이름으로 로그인. 한 번 로그인하면 나가기 전까지 유지 |
| 랭킹 | 가입한 모든 사람의 항목별(타수·게임 점수·연습 횟수) 순위 |

- 타수(타/분)와 정확도를 한컴 방식과 같이 **자모 단위**로 계산합니다.
- 글자 크기 3단계, 효과음, 화면 자판 표시, 낱말 읽어주기(TTS) 설정을 제공합니다.
- 계정과 최고 기록은 Supabase에 저장됩니다(`supabase/accounts.sql`). 비밀번호는 bcrypt 해시로만 저장되고, 표는 anon 키로 직접 읽을 수 없으며 함수(`account_signup/login/refresh/save/ranking`)로만 접근합니다. 로그인 세션·내 글(비공유)·설정은 브라우저 `localStorage`에 남습니다.

## 화면 디자인

사용자가 제공한 “Shades in the Rainbow” 팔레트의 연보라·라일락·하늘색·민트·크림옐로·살구색을 버튼과 다섯 개의 연습·게임 카드에 적용했습니다. 밝은 바탕에 짙은 보라 계열의 글씨를 사용합니다. 짙은 본문과 안내 글씨, 입체적인 키보드 이미지로 가독성과 편안한 분위기를 함께 살렸습니다. 홈에서 3단계 연습과 게임을 나누어 보여 주고, 상단 메뉴로 연습·게임·기록을 바로 이동할 수 있습니다.

- 휴대전화부터 넓은 모니터까지 대응하는 반응형 화면
- 글자 크기 3단계와 키보드 탐색, 눈에 보이는 포커스, 움직임 줄이기 설정 대응
- 설정은 `Escape` 또는 닫기 버튼으로 닫을 수 있습니다.
- 자체 SVG 아이콘과 CSS 게임 그림을 사용하며, 추가 라이브러리나 빌드가 필요하지 않습니다.
- 메인 이미지와 생성 프롬프트: [assets/README.md](assets/README.md)

## 3D 게임 구조

- `game-design/`: 별도 터미널에서 만든 디자인 패키지(Three.js 장면, GLB 모델, HUD UI). `ui.js`/`scene.js`/`styles.css`/`models/`/`vendor/`만 실제 게임이 사용하며, `demo.js`·`fixtures.js`·`index.html`은 디자인 미리보기용입니다.
- `js/play.js`: `#/race`, `#/tennis` 라우트. 게임에 들어갈 때만 3D 모듈을 동적으로 불러옵니다. `index.html`의 import map이 Three.js 경로를 정합니다.
- `js/play/race.js`, `js/play/tennis.js`: 게임 규칙. 온라인 방에서는 입장 순서가 가장 빠른 사람(방장)이 심판 역할을 하고 나머지는 상태를 받아 표시합니다.
- `js/play/net.js`: Supabase Realtime(Presence + Broadcast)로 방을 만듭니다. 표는 쓰지 않습니다. 방 주소는 `#/race/CODE`, `#/tennis/CODE`이며 `QUICK` 방이 "상대 찾기"에 쓰입니다.
- `data/common-words.txt`: 컴퓨터가 쉬움·보통 난이도에서 내는 친숙한 낱말 목록(사전 검증 완료). 없으면 컴퓨터가 공을 놓칩니다.
- `js/play/dict.js`: 끝말잇기 사전. `data/dict/{0..18}.txt`는 국립국어원 표준국어대사전 표제어(acidsound/korean_wordlist 기반)를 한글 2~5음절만 남겨 첫 자음별로 나눈 것으로, 필요한 조각만 불러옵니다. 두음법칙은 양방향으로 허용합니다. 뜻풀이(`data/mean/{0..18}.json`)는 국립국어원 표준국어대사전 기반 acidsound/korean_wordlist의 풀이를 2~3음절 낱말만 짧게 줄인 것이며, 자주 쓰는 낱말 340여 개는 직접 쓴 풀이로 바꿨습니다.

## 함께 보는 글 관리

- 저장소: Supabase 무료 프로젝트의 `shared_texts` 표. 사이트에는 공개용 anon 키만 들어 있으며, 행 수준 보안(RLS)으로 읽기·추가만 허용됩니다.
- 삭제: `delete_shared_text(id, pin)` 함수가 올릴 때 저장한 비밀번호 해시와 비교해 지웁니다. 관리자는 Supabase 대시보드의 Table Editor에서 아무 글이나 지울 수 있습니다.
- 사이트는 목록을 2분 동안 브라우저에 캐시합니다.
- 무료 플랜은 7일 동안 요청이 없으면 프로젝트가 일시 정지되며, 대시보드에서 Restore 하면 됩니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```
