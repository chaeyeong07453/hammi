# 함미합삐 타자연습 ⌨️

할머니, 할아버지를 위한 **큰 글씨 · 쉬운 구성**의 한글 타자연습 사이트입니다.
한컴타자연습의 골격(낱말 → 짧은글 → 긴글)을 따르고, 미니게임 2종을 더했습니다.

## 구성

| 메뉴 | 내용 |
|---|---|
| 1단계 낱말연습 | 쉬운 낱말(520개) / 긴 낱말(360여 개) 중 매번 15개를 무작위로. 다 치면 자동으로 다음 낱말 |
| 2단계 짧은글연습 | 속담 / 일상 문장 10개. 띄어쓰기와 문장 부호 포함 |
| 3단계 긴글연습 | 진달래꽃, 서시, 애국가, 흥부와 놀부 등을 한 줄씩. **내 글 넣기**로 노래 가사·시를 직접 넣어 연습 가능 (브라우저에 저장). **모두에게 공유하기**를 누르면 이 저장소의 이슈로 올라가고, `text` 라벨이 붙은 열린 이슈는 모든 방문자의 "함께 보는 글" 목록에 나타남 |
| 게임 · 낱말비 | 떨어지는 구절·속담·문장을 바닥에 닿기 전에 치기 (빠르기에 따라 짧은 구절 → 긴 문장) |
| 게임 · 낱말 두더지 | 두더지가 든 낱말을 45초 동안 쳐서 잡기 (빠르기에 따라 낱말 길이 증가) |
| 로그인 / 회원가입 | 이름 + 숫자 4자리 비밀번호. 서버 없이 브라우저에 저장되며, 한 번 로그인하면 나가기 전까지 유지 |
| 랭킹 | 같은 컴퓨터에서 연습한 사람들끼리 항목별(타수·게임 점수·연습 횟수) 순위 비교 |

- 타수(타/분)와 정확도를 한컴 방식과 같이 **자모 단위**로 계산합니다.
- 글자 크기 3단계, 효과음, 화면 자판 표시, 낱말 읽어주기(TTS) 설정을 제공합니다.
- 계정, 최고 기록, 내 글, 설정은 모두 브라우저 `localStorage`에만 저장됩니다. 서버가 없으므로 다른 컴퓨터와는 공유되지 않습니다.

## 화면 디자인

사용자가 제공한 “Shades in the Rainbow” 팔레트의 연보라·라일락·하늘색·민트·크림옐로·살구색을 버튼과 다섯 개의 연습·게임 카드에 적용했습니다. 밝은 바탕에 짙은 보라 계열의 글씨를 사용합니다. 짙은 본문과 안내 글씨, 입체적인 키보드 이미지로 가독성과 편안한 분위기를 함께 살렸습니다. 홈에서 3단계 연습과 게임을 나누어 보여 주고, 상단 메뉴로 연습·게임·기록을 바로 이동할 수 있습니다.

- 휴대전화부터 넓은 모니터까지 대응하는 반응형 화면
- 글자 크기 3단계와 키보드 탐색, 눈에 보이는 포커스, 움직임 줄이기 설정 대응
- 설정은 `Escape` 또는 닫기 버튼으로 닫을 수 있습니다.
- 자체 SVG 아이콘과 CSS 게임 그림을 사용하며, 추가 라이브러리나 빌드가 필요하지 않습니다.
- 메인 이미지와 생성 프롬프트: [assets/README.md](assets/README.md)

## 함께 보는 글 관리

- 글 추가: 사이트의 긴글연습 → 새 글 넣기 → 모두에게 공유하기 (GitHub 로그인 필요), 또는 이 저장소에 `text` 라벨을 붙여 이슈 작성. 이슈 제목이 글 제목, 본문이 내용이며 첫 줄을 `지은이: 이름`으로 쓰면 지은이로 표시됩니다.
- 글 삭제: 해당 이슈를 닫으면(Close) 목록에서 사라집니다.
- 사이트는 GitHub 공개 API로 읽으며 5분 동안 브라우저에 캐시합니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```
