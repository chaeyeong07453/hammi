# Hammi Play · 3D 게임 디자인

사용자가 지정한 파스텔 6색을 적용한 **단어 드라이브**와 **끝말 테니스**의 독립 디자인 미리보기입니다. Blender 원본, GLB 모델, Three.js 장면, 반응형 게임 UI와 상태 예시를 포함합니다.

프로젝트 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1` 실행 후:

- [자동차 화면](http://localhost:8000/game-design/#race)
- [테니스 화면](http://localhost:8000/game-design/#tennis)

**실제 게임 규칙·온라인 연결은 들어 있지 않습니다.** 하단 선택기로 화면 상태를 바꾸고, 입력창으로 정해진 성공 연출을 확인할 수 있습니다.

개발 연결과 표시 상태·이벤트 규격은 [HANDOFF.md](HANDOFF.md)를 읽어 주세요. Blender 편집 원본은 [hammi-play.blend](blender/hammi-play.blend), 확인용 이미지는 [previews](previews/)에 있습니다.
